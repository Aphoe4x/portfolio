02 About

A backend developer who still shows up to the table.

I am Afolabi Abdulbasit Opeyemi, a backend-leaning full-stack developer in Lagos. Most of my work is PHP and Laravel on the server, Node.js when a project calls for it, and interfaces built in plain JavaScript, React or Tailwind.

I've shipped for teams in the UK, Canada and Nigeria: a WordPress site for a national employment organization, payment flows for an art marketplace, a multi-company booking marketplace, an online shop, and a Whot game with realtime rooms. I finished HNG15 as a finalist along the way.

I like small tools that solve one problem well, tests that catch real mistakes, and code someone else can pick up on a Monday. When I'm not building, I'm usually losing at my own card game.
